# Layout

## Layout

![](<../../.gitbook/assets/image (96).png>)



The layout tab displays a full preview of your show and provides a view of how all the models will appear. In addition you can :

* Define new Models or change existing Model definitions.
* Define new Model Groups or change existing Model Group definitions.
* Select which Models, or Model Groups are be displayed on the Layout.
* Select and adjust the layout background.
* Specify, position and adjust the model size, orientation and location on the layout.
* Check whether any models have overlapping channels.
* Review or change the detailed characteristics of a model’s attributes
* Create Additional Preview layout windows
* Assign Models to one or more Preview Layouts
* Assign Models to Specific Controller Connection
* Assign the Model Start Channels

![](<../../.gitbook/assets/image (944).png>)

## Show Names and Start Channels

The Layout tab provides **Show Names** and **Show Start Channel** checkboxes. When enabled, the layout preview overlays each model's name and its controller/port or start channel directly on top of the model. This makes it easy to confirm at a glance how models are addressed without opening each model's properties.

## Filter the Model List

A filter box above the model list lets you quickly narrow a large list of models and groups. The filter matches using a regular expression, so you can type a partial name or a pattern to show only the models you are interested in.

## Docking and Floating Panels

The Layout tab panels (the model list and the model properties) are dockable and floatable. You can drag a panel out of its default position to float it as a separate window, or re-dock it elsewhere in the Layout tab. This is useful on multi-monitor setups or when you want more room for the preview.

## Edit Display Elements

An **Edit Display Elements** panel is available on the Layout tab, similar to the one in the Sequencer tab. It lets you choose which models, groups and timing tracks are shown without leaving the Layout tab. A filter box above the *Available* list helps you quickly find a model, group or timing track to add in large shows; the filter clears automatically once items are moved into the view.

## Replace Model

The **Replace Model** option lets you replace one model with another. A dialog presents a filtered, checkbox list of target models so you can replace several models at once. Options control whether the replacement keeps the original position and size. Locked, base-linked and two-point models are handled appropriately, and base-linked models cannot be used as replacement targets.
