# Label Model

### Label Model

The Label Model is a simple text model that displays a line of text directly in the layout and preview. It does not control any lights or channels - instead it is used to annotate the layout, add signage, mark areas of a display, or otherwise place readable text alongside your other models. The text is drawn centered on the model and scales with the model's size in the layout.

The following properties are available for the Label Model:

| **Options/Setting** | **Description** |
| --- | --- |
| **Label Text** | The text that is displayed by the model. Defaults to "Label". |
| **Font Size** | The font size used to render the text. Can be set between 8 and 40, with a default of 14. |
| **Text Color** | The color used to draw the text. Defaults to white. |
