### Wreath Model

{% hint style="warning" %}
Depreciated: Use Circle Model Instead
{% endhint %}

The # Strings is the physical number of strings connected to the controller. Nodes/String is the nodes/pixels per light string.

## Model Settings

<!-- TODO: screenshot -->

| **Options/Setting** | **Description** |
| --- | --- |
| **# Strings** | Physical number of strings connected to the controller (typically the number of connections from the prop to your controller). Range 1&ndash;640. |
| **Nodes/String** | Number of nodes/pixels per string (typically the total number of pixels per string). Range 1&ndash;640. For single-channel string types this property is labelled **Lights/String** instead. |
| **Starting Location** | Where the wiring starts and which way it winds: **Top Ctr-CCW**, **Top Ctr-CW**, **Bottom Ctr-CW**, or **Bottom Ctr-CCW**. |
