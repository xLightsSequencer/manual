# Kaleidoscope

![](<../../.gitbook/assets/image (1029).png>)

The Kaleidoscope Effect is a canvas mode effect. By itself it does nothing. It must be placed above another effect and it will modify the output. A Kaleidoscope will sample a section of the underlying effect and mirror it into a symmetrical pattern. A "Square" kaleidoscope type will use a square shaped sample area and a triangle type will use a triangle shaped area. Additional kaleidoscope pattern types are also available in the Kaleidoscope Type dropdown beyond Square and Triangle, each producing a different symmetrical arrangement. The "Size" , "Center X", and "Center Y" determines the location/size of the sampling area.

| Option/Settings       | Description                                                                            |
| --------------------- | ------------------------------------------------------------------------------------- |
| **Kaleidoscope Type** | Selects the kaleidoscope pattern. Square and Triangle plus several additional patterns. |
| **Center X**          | Center X of the Kaleidoscope Sampling Area |
| **Center Y**          | Center Y of the Kaleidoscope Sampling Area |
| **Size**              | Size of the Kaleidoscope Sampling Area     |
| **Rotation**          | Set Rotation of the Kaleidoscope Output    |
